# Security Policy

## Supported versions

Only the latest default branch is supported.

## Report a vulnerability

Do not open a public issue for a security vulnerability. Contact the repository maintainer privately with:

- a description of the issue;
- affected files or endpoints;
- reproduction steps;
- impact and suggested mitigation, if known.

Do not include passwords, tokens, or private learner data in a report.

Please allow time for investigation and a fix before public disclosure.
